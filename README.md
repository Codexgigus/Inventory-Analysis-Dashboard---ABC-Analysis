# Inventory-Analysis-Dashboard---ABC-Analysis

This project is a Power BI business intelligence dashboard focused on ABC inventory analysis and product performance optimization. The objective is to help management identify which products contribute the most to revenue, evaluate inventory efficiency, and make smarter purchasing and stock control decisions.

The dashboard combines sales, stock, cost, pricing, category, and turnover data to provide a complete view of product performance across multiple dimensions such as product, category, and country.

Using ABC classification (Pareto-based segmentation), products are grouped into:

A Class → highest revenue contributors (critical products)
B Class → medium-value contributors
C Class → low-value contributors

This allows decision-makers to focus attention on the most impactful inventory items while reducing inefficiencies in lower-priority stock.
